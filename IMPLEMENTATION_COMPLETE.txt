Two-layer fix to prevent false drug extraction in consumption-only cases
(where drugs are mentioned as consumed/tested positive, but NOT seized).

LAYER 1: LLM Rule 13 (Primary)
  Location: /brief_facts_ai/extractor_drugs.py (lines 812-831)
  Content: Added explicit instruction to EXTRACTION_PROMPT
  Effect: LLM skips extraction if consumption-only (no seizure)

LAYER 2: Post-Filter Function (Backup)
  Location: /brief_facts_ai/extractor_drugs.py (lines 943-1017)
  Function: filter_consumption_only_drugs(drugs, text)
  Effect: Catches any LLM misses with heuristic filtering

LAYER 3: Pipeline Integration
  Location: /brief_facts_ai/extractor_drugs.py (lines 1810-1814)
  Step: 4b (after KB resolution, before non-drug filtering)
  Effect: Filter automatically applied to all drug extractions
